Signal Playground

A small collection of experiments for understanding basic signals, sampling, and signal manipulation using Python.

Objectives
1. Generate a Sine Wave
Generate a discrete-time sine wave using NumPy.
Control:
Amplitude
Frequency
Phase
Sampling rate
Duration
Plot the signal in the time domain.

2. Explore Signal Parameters

Experiment with changing:

Amplitude
Frequency
Phase
Sampling rate

Observe how each parameter changes the resulting signal.

3. Combine Signals
Generate two or more sine waves.
Add them together.
Visualize the resulting composite signal.
Observe how multiple frequency components appear in a single signal.

4. Add Noise
Generate a clean signal.
Add random noise to it.
Compare the clean and noisy signals.
Observe how increasing noise affects the signal.

5. Explore Sampling

Experiment with different sampling rates.

Sample a signal at a high enough rate.
Reduce the sampling rate.
Observe how the discrete samples represent the original signal.

6. Demonstrate Aliasing

Create an experiment where the sampling rate is too low for the signal frequency.

Observe the resulting sampled signal.
Compare it with the original signal.
Understand why the sampled signal can appear to have a different frequency.

7. Build a Small Signal Playground

Combine the previous experiments into a simple program where the signal parameters can be changed easily.

The playground should allow experimentation with:

Frequency
Amplitude
Phase
Sampling rate
Noise
Multiple signal components
Final Goals

By the end of this project, I should be able to:

Generate and visualize basic signals.
Understand amplitude, frequency, and phase.
Understand discrete-time sampling.
Explain the effect of sampling rate.
Demonstrate aliasing experimentally.
Combine multiple signals.
Add and analyze noise.
Use Python, NumPy, and Matplotlib for basic DSP experimentation.
Learning Process
Theory
   ↓
Experiment
   ↓
Code
   ↓
Plot
   ↓
Observe
   ↓
Explain

The goal is not to build a production application. The goal is to play with signals until their behavior becomes intuitive.
